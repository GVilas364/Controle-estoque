# Controle de Estoque

Sistema simples de controle de estoque para pequenas empresas, desenvolvido como projeto do curso de Desenvolvimento de Software Assistido por Inteligência Artificial (DSAIA).

## Sobre o projeto

O Controle de Estoque tem como objetivo facilitar a organização de produtos e o acompanhamento das quantidades disponíveis em pequenas empresas.

A proposta é criar uma aplicação simples e prática, que ajude a reduzir erros no controle manual de mercadorias e facilite a consulta das informações.

O projeto será desenvolvido gradualmente, com novas funcionalidades sendo adicionadas conforme o avanço dos estudos.

## Funcionalidades planejadas

* Cadastrar produtos com nome, quantidade e preço.
* Listar os produtos cadastrados.
* Atualizar a quantidade dos produtos.
* Salvar e recuperar os dados dos produtos.

## Tecnologias

- **Python:** linguagem utilizada no desenvolvimento.
- **JSON:** formato utilizado inicialmente para armazenar os dados.
- **Visual Studio Code:** ambiente de desenvolvimento.

## Estrutura inicial

A estrutura dos arquivos será definida durante o desenvolvimento do projeto.

## Objetivos de aprendizagem

- Praticar lógica de programação com Python.
- Aprender a organizar o código em funções.
- Trabalhar com listas, dicionários e arquivos JSON.
- Utilizar inteligência artificial como apoio ao desenvolvimento de software.
- Desenvolver o projeto de forma incremental, compreendendo cada etapa.
